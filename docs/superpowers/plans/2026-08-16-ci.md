# CI 導入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GitHub Actions で AGENTS.md の pre-commit ゲート + smoke テスト + flake ビルドを自動実行する。

**Architecture:** Nix ベース。`flake.lock` でピンされた dev シェル（devShells.default）を CI でも使用し、ローカルとツールチェーンを完全一致させる。製品コードの変更なし。ランナーは ubuntu-latest のみ（macOS は CI 分 10 倍・coreutils 追加が必要なため見送り、後から拡張可能）。bench は CI では実行しない（`cargo check --all-targets` でコンパイル検証のみ）。

**Tech Stack:** GitHub Actions, Nix (flake), Rust toolchain via nixpkgs pin

**Spec:** なし（bounded なインフラ設定タスク。設計は本プランが担う）

## Global Constraints

- CI のコマンド列は AGENTS.md の pre-commit ゲートと同一の内容であること（ただし fmt は非変更の `--check` を使用、clippy は `-D warnings` で 0 警告を強制）
- ランナー: ubuntu-latest / Nix (cachix/install-nix-action) / flake 有効
- キャッシュ設定は初期版では入れない（YAGNI。遅くなったら後で追加）
- コメントは英語
- コミットはユーザー事前承認済み（2026-08-16 確認済み）
- スコープ外: macOS ランナー、bench 実行ジョブ、キャッシュ、devShell の変更（なし）、製品コードの変更（なし）

### Task 1: GitHub Actions ワークフロー作成

**Files:**
- Create: `.github/workflows/ci.yml`
- Modify: `AGENTS.md`（Commands に 1 行追加）

- [ ] **Step 1: ci.yml を作成** — `.github/workflows/ci.yml`:

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:

jobs:
  # The AGENTS.md pre-commit gate plus the shell integration smoke
  # test, run inside the pinned Nix dev shell so CI matches local
  # development exactly.
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: cachix/install-nix-action@v27
      - name: Pre-commit gate
        run: nix develop -c bash -c 'cargo fmt --check && cargo check --all-targets && cargo clippy --all-targets -- -D warnings && cargo test'
      - name: Shell integration smoke test
        run: nix develop -c bash -c 'cargo build --release && bash tests/bash/smoke.sh target/release/seasalt'

  # Verifies the flake package itself builds (a separate path from
  # building with cargo directly).
  nix-build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: cachix/install-nix-action@v27
      - name: Build the package via the flake
        run: nix build .#default
```

- [ ] **Step 2: AGENTS.md に CI の 1 行を追加** — Commands セクションの `Install: ...` の行の後に追加:
